PERSONAL DBA PORTFOLIO WEBSITE

Files:
- index.html: Main portfolio page
- styles.css: Responsive visual design

How to view:
1. Extract the ZIP file.
2. Keep index.html and styles.css in the same folder.
3. Double-click index.html to open it in a browser.

Notes:
- The page is responsive for desktop, tablet, and mobile.
- The email and phone links are clickable.
- Google Fonts are loaded online; the page still works offline using fallback fonts.
- The LinkedIn label from the résumé was not linked because the résumé did not include a profile URL.
- All résumé experience and credentials are presented without adding unverified dates or qualifications.
